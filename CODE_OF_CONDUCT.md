# Code of Conduct

This project adopts the **Contributor Covenant, version 3.0**:
<https://www.contributor-covenant.org/version/3/0/code_of_conduct/>

In short: be respectful, assume good faith, and no harassment of any kind, in issues, pull requests,
discussions or anywhere else you represent this project.

## Reporting

Report conduct problems to the maintainer at **origin@rgnrk.co**. Reports are kept private. The maintainer
decides what happens next, following the enforcement guidance in the Contributor Covenant.

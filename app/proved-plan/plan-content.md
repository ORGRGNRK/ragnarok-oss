# Proved — launch plan (content for the checklist page)

Product: "Proved" (working name) — the agent runner from Heimdall (bin/ragnarok-agent) as a standalone open-source
CLI: the agent's "done" isn't believed; every proof is a command Ragnarok runs; a separate critic checks; walls are
enforced before the move. Paid side: "AI work done with proof" jobs for small businesses and small dev teams, using
~/client-kit (agreement, audit log, proof report).

## Daily rhythm (every day, repeatable — resets each day)
- post: Post — 20 min — one post from yesterday's work
- product: Product — 60–90 min — that day's task
- outreach: Replies and outreach — 20 min — answer people, message 2 contacts
- system: Your system — the rest — normal work; note anything worth posting

## Daily numbers (logged once a day)
posts, replies, stars, outreach, calls, paid

## Week 1 — pull it out
- d1: Pick the name, create the repo, check the name/handle/domain are free
- d2: Copy the runner in; make the ~70 setup-specific lines optional (receipts, Alexus referee, Ollama, your name)
- d3: One-command install; README whose first screen is a 60-second example
- d4: Record demo 1: agent says done, a proof fails, it gets sent back
- d5: Record demo 2: walls blocking curl, a Desktop write and a second "once" (re-run the wall test)
- d6: Run it on 3 real open-source issues; keep the logs as case studies
- d7: Scan for secrets and personal details (IPs, paths, keys) before anything goes public

## Week 2 — launch
- d8: Set up the accounts; pin demo 1
- d9: Publish the repo; post demo 2
- d10: Write up the Facebook run (52 calls and why) as a post
- d11: Post to Show HN and the Claude subreddit (read their posting rules first)
- d12: Answer every issue and comment the same day
- d13: Fix the top complaint
- d14: Review: which post did best? Do more of that

## Week 3 — the paid offer
- d15: Write a one-page offer: what you do, the proof report they get, the price
- d16: Merge Proved into client-kit so every client job runs proved
- d17: Contact the first 4 of 10 people (Tracy-area list, local businesses, dev contacts)
- d18: Contact the next 3; offer the first 3 jobs at an intro price
- d19: Contact the last 3; follow up on day 17's
- d20: Run a booked job; post the proof report with the client's permission
- d21: Run a booked job; post the proof report with the client's permission

## Week 4 — measure and decide
- d22: Keep the rhythm; pick one improvement users asked for
- d23: Build it
- d24: Build it
- d25: Ship it and post it
- d26: Keep the rhythm
- d27: Add up the numbers: stars, issues, calls, paid jobs, best post kind
- d28: Decide: jobs came in → double down on the service; only stars → build paid team features next
